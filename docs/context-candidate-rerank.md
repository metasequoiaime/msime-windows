# 词库上下文重排：实验实现与验证

实验分支：`experiment/context-candidate-rerank`，基于 `develop`。

## 实现范围

`quanpin::rerank_dictionary_candidates` 对完整读音匹配的前 32 个词库候选做后台重排，
全拼在 `query_exact` 合并完成后接入，双拼在 `generateSeries` 合并完成后接入。
只交换这些词库行的位置，保留候选来源、读音和权重，不写回数据库。

评分复用轻量 `sentence-model.safetensors` 和 `RescoreWorker`，参考最近 64 个字符。
词频先验转换为对数后，与神经对数分数按 20% / 80% 插值。轻量模型对示例
「冬天会下大」后「雪」相对「学」的分差较小，沿用整句的 50% 比例会被词频抵消，
所以本实验使用独立比例。它不是保证任意语境都选对的规则系统。

生成整句、在线候选、前缀词、模糊音、纠错读音不参与这一轮排序。辅助码与手动固定
位置仍在后续流程生效。无前文、无模型或关闭开关时保持原排序。

重排结果写入既有 series cache；上文变化与后台完成时沿用原有的失效和重查链路。
后台键包含模型、前文、候选列表、先验分数和评分参数，避免词库与整句互用不兼容结果。

## 配置接线

`SentenceAssociationOptions::context_candidate_rerank` 对应
`[association] context_candidate_rerank = false`，默认关闭。
Server 配置读写、出厂模板、开发模板、设置进程 snapshot/update 与原生开关均有映射。
设置入口在输入页「整句与云候选」区域的「上文词库重排（实验）」。
此开关独立使用轻量模型，不依赖神经整句或 Trigram 显示开关。

## 验证

使用隔离的真实词库副本与模型，运行：

```powershell
$env:METASEQUOIA_IME_DATA_DIR = '<隔离测试数据目录>'
ctest --test-dir engine/build-local -C Release -R '^neural_sentence$' --output-on-failure
```

覆盖全拼 `xue` / 小鹤双拼 `xt` 在「冬天会下大」后提升「雪」，换成
「我们正在学校里上」后提升「学」，以及「上海 / 伤害」的词组消歧。
另外覆盖清空上下文、关闭开关、候选元数据保留、缓存先验/参数隔离，以及
实际 `InputSession` 的手动固定首位覆盖模型结果。

原生宿主手工复现时，需在同一焦点会话通过输入法选词上屏前文，再输入待转换拼音。
前文仍来自当前焦点会话的提交历史，不读取现有文档；粘贴、删除与光标移动不会同步
这份历史。原生编辑框交互与安装验证应单独执行，不能用上述引擎测试代替。

## 已复现的连续上下文局限

轻量模型在单独前文「我明天要上」下给「学」的分数高于「雪」，但在无分隔的累积前文
「冬天会下大雪我明天要上」下会反选「雪」。效果档模型在这两种前文下都偏向「学」。
当前词库重排固定使用轻量模型，效果档整句开关不会切换词库重排模型；上下文历史也
不会自动识别没有标点的新句。独立语境测试通过不能证明连续输入时的消歧准确率。
