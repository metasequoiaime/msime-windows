# 时崎狂三 Demo

候选框以时崎狂三与转动的金色钟盘为动态背景：180×320 的循环 GIF 以 `cover` 居中铺满卡片，盖在近黑的底色上并压到半透明，候选文字用奶油白，选中项是深红底、金色序号与选中竖条。背景本身是暗红与金色，深浅两套主题用同一套暗色，右键菜单与悬浮工具栏配色一致。

原图为 50 帧 × 100 ms、约 1 MB，超过单张图片 500 KB 的上限，这里隔帧抽取为 25 帧 × 200 ms（循环时长不变），约 450 KB。背景是竖图，竖排时比例接近原图；横排时露出的是画面中段持枪的手与钟盘。

## 本地查看

仅在具备素材使用许可的环境中，将整个目录复制到数据目录的 `skins/tokisaki/`，在设置页刷新皮肤并选择「时崎狂三 Demo」。
