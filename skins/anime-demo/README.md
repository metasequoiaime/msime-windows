# anime-demo

候选窗的浅色主题为奶油底与深棕文字，深色主题为可可棕底与奶油白文字，两套主题分别定义选中项、序号、翻译与右键菜单颜色。面板使用原生圆角底色，不依赖固定颜色的面板图片，横排和竖排共用相同配色与留白。候选框右上角挂着一只循环播放的猫猫虫 GIF，脚底刚好踩在面板的上边框上，不遮挡文字；左下角挂着一只抱樱花枝的小白猫（`sakura-kitten.png`），大半伸出面板左侧，只有尾巴压进面板；正下方居中倒挂着一位戴帽子的长发少女（`hanging-girl.png`），帽子截口贴着面板下边框；右下角用绳子吊着一个野猪头少年（`boar-warrior.png`），绳头贴着面板下边框。

悬浮工具栏使用布朗熊敲电脑的 APNG，右侧按钮共用奶油色圆底和深棕图标；按钮通过 `button_flow` 竖排，关闭按钮时圆底一起隐藏，后面的按钮自动补位。

## 本地查看

仅在具备素材使用许可的环境中，将整个目录复制到数据目录的 `skins/anime-demo/`，在设置页刷新皮肤并选择「anime-demo」，切换深浅预览检查两种候选窗。此目录不是内置皮肤，也不加入官方皮肤名单。
