帮助

水杉输入法是一款 Windows 平台的中文输入法。目前支持 Windows11/Windows10 平台。

完整的使用说明见 Wiki，遇到问题可以先查看 常见问题（FAQ）。

快速上手

安装输入法后，可以使用 Win + Space 快捷键切换到水杉输入法。默认是全拼输入法。

基本功能

支持全拼、双拼和五笔。可以在设置窗口下的输入功能分区进行切换。全拼和双拼均支持辅助码。辅助码方案目前支持自然码辅助码、蓝天小雨点、首右2.0、首右plus、小鹤和拼音加加，也可以把自己的辅助码文件放进数据目录下的 helpcodes\custom 文件夹导入。可以在设置的辅助码分区进行辅助码的开关和切换。打字过程中，全拼使用辅助码需要用大写的字母唤起单码和双码辅助。双拼在开启辅助码的状态下默认使用单码辅助，第二个码是大写字母的情况下，则会使用完整双码进行筛选。

语音识别和 AI 联想需要自行填入 API 和 token。内测期间，将默认使用开发者个人的 api 和 token，仅供测试使用。云联想目前支持谷歌的云接口，请用户注意网络问题，需要时可在下方设置网络代理。

更多功能欢迎自由探索~

默认输入法
设为默认后，水杉输入法会排在系统设置「语言和区域 → 中文（简体）」键盘列表的第一位，切到中文时直接使用水杉输入法。不会改动语言顺序和界面语言

游戏兼容（CS2 / Dota 2）
CS2、Dota 2 只给内置名单里的输入法画候选；不在名单里时会在左上角弹出系统组合小框，独占全屏下还会把游戏踢出全屏（黑屏）。开启后水杉在系统里登记为下面的名称，游戏会自己画候选。
代价：语言栏和 Windows 设置里也会显示这个名称；需要管理员权限（会弹一次 UAC）；要重启游戏才生效；已知上屏后的第一下退格会被游戏吞掉（游戏那边的行为）。

网络代理
云输入、语法模型下载、AI 联想、翻译和语音识别等联网功能共用这里的设置，修改后立即生效
仅支持 HTTP 代理，格式为「主机:端口」，如 127.0.0.1:7890；Clash、v2rayN 等客户端的 HTTP/混合端口均可
