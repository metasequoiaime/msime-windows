Server 端日志
排查 Server 通信和输入延迟时开启。记录慢请求阶段、候选窗、悬浮工具栏、菜单、焦点会话和通信状态，不记录按键、输入内容或候选文本。日志默认保存到桌面的“水杉IME诊断日志.log”，复现后可直接发送该文件。
TSF 端日志
排查应用内预编辑和输入延迟时开启。TSF 日志会在内存中限量缓冲，并通过独立管道批量汇总到桌面的“水杉IME诊断日志.log”；不记录按键、输入内容或候选文本。
